# Akshay Naik — personal website

This repository contains the generated portfolio and its GitHub Pages deployment workflow. The website is published from `public/`; private background documents, source photographs, and internal notes are excluded.

Updates are prepared in the local website workspace with `npm run prepare:publish`, then committed and pushed to this repository's `main` branch. Enable **Settings → Pages → Source → GitHub Actions** for the first deployment. Each push publishes the prepared website automatically.

Edit the original website workspace rather than generated files in this repository.
